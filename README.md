# Tempera.id - Siap Upload - Design 100% Asli

## Struktur:
- index.html = file asli kamu, design 100% sama, sudah modular
- css/main.css = CSS asli
- js/config.js = tambah driver disini
- driver/udin/ = halaman driver (design sama persis + badge driver)

## Cara upload:
1. Upload semua file ke hosting (Vercel, Netlify, cPanel)
2. Akses tempera.id -> induk
3. Akses tempera.id/driver/udin/ -> halaman driver

## Tambah driver baru:
Edit js/config.js -> drivers array, tambah object baru, lalu copy folder driver/udin/ jadi driver/budi/
